# Работа команды SatuCard

Этот файл описывает фактическую историю и порядок дальнейшей работы. Автор каждого коммита определяется настройками Git и подтверждённым адресом в его аккаунте GitHub; вход в браузер другого человека сам по себе не меняет автора уже сделанных коммитов.

## Уже выполнено

- `nurlybekchel`: тема сайта и её сохранение при переходе между страницами.
- `Sanzhar425`: название магазина, логотип и выбор цвета ценника в редакторе.
- `munarsauyt-sketch`: исходная сборка проекта и работа над публикацией карточки через сервер.

Проверяйте вкладку **Commits** и отдельные изменения, когда рассказываете о личном вкладе. Не создавайте пустые коммиты ради количества и не приписывайте чужие изменения участникам.

## Следующая работа

1. Каждый участник клонирует репозиторий и создаёт свою ветку от актуальной `main`.
2. Перед коммитом настраивает свои `git user.name` и `git user.email` в локальной копии.
3. Делает работающие изменения, проверяет их, затем коммитит завершённые этапы.
4. Открывает Pull Request в `main`. После проверки объединяйте через **Create a merge commit**, чтобы этапы работы сохранились в истории.

Для РК1 сначала проверьте действующий URL сайта, публикацию карточки, серверную запись и чтение из базы. Для демонстрации используйте собственную карточку и покажите запись в Supabase. ИИ не заявляйте как готовую функцию: интеграция запланирована на 8–15 недели.
