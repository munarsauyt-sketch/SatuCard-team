# SatuCard

SatuCard — учебный сервис для продавцов Казахстана. В редакторе можно загрузить фотографию товара, указать название и цену в тенге, выбрать оформление, добавить название и логотип магазина. Карточка видна сразу; её можно скачать в PNG. После явного нажатия «Опубликовать» готовое изображение сохраняется на сервере и открывается по ссылке.

**Сайт:** [satucard-team.vercel.app](https://satucard-team.vercel.app/).

**Приложение:** [`SatuCard-team-starter/`](SatuCard-team-starter/).

## Что уже работает

- Три страницы сайта и адаптация под телефон.
- Редактор с тремя стилями, двумя форматами, скидкой, настройкой положения фото и фирменного оформления.
- Локальное скачивание PNG без отправки исходной фотографии на сервер.
- Публикация готовой карточки через серверные функции: изображение в Supabase Storage, название и цена в PostgreSQL; публичная страница по ссылке.
- Светлая и тёмная темы.

ИИ, удаление фона, аккаунты и отправка на маркетплейсы пока не реализованы. Интеграция ИИ запланирована на 8–15 недели учебного проекта.

## Развёртывание

Сайт развёрнут на Vercel, а таблица карточек и изображения находятся в Supabase. См. [инструкцию приложения](SatuCard-team-starter/README.md). Сервер использует секретный ключ Supabase только в переменных окружения Vercel; не добавляйте его в GitHub.
