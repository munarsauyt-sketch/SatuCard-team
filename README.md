# SatuCard

SatuCard — учебный сервис для продавцов Казахстана. В студии можно загрузить фотографию товара, собрать тексты, характеристики и цены, выбрать шаблон, настроить фото, цвета, шрифт и фирменное оформление магазина. Карточка видна сразу; её можно скачать в PNG/JPEG, сохранить редактируемый проект или продолжить локальный черновик. После явного нажатия «Опубликовать» готовое изображение сохраняется на сервере и открывается по ссылке.

**Сайт:** [satucard-team.vercel.app](https://satucard-team.vercel.app/).

**Приложение:** [`SatuCard-team-starter/`](SatuCard-team-starter/).

## Что уже работает

- Страницы сайта и адаптация под телефон.
- Единая визуальная система на шести страницах, интерактивный пример на главной, сравнение фото и карточки, галерея восьми шаблонов с фильтрами и выбором товара.
- Студия с восемью шаблонами, тремя форматами, настройками фото и текста, скидкой и фирменным оформлением.
- Локальное скачивание PNG/JPEG 1×/2× без отправки исходной фотографии на сервер.
- Отмена/повтор, локальное автосохранение с фото и переносимый файл проекта.
- Публикация готовой карточки через серверные функции: изображение в Supabase Storage, название и цена в PostgreSQL; публичная страница по ссылке.
- Регистрация и вход через Supabase Auth, личный профиль и список опубликованных карточек.
- Светлая и тёмная темы.

ИИ, удаление фона и отправка на маркетплейсы пока не реализованы. Интеграция ИИ запланирована на 8–15 недели учебного проекта.
В учебной версии подтверждение email отключено из-за ограничений встроенной почтовой отправки Supabase. Для публичного коммерческого запуска потребуется настроить SMTP и включить подтверждение адреса.

## Развёртывание

Сайт развёрнут на Vercel, а Auth, PostgreSQL и Storage находятся в Supabase. См. [инструкцию приложения](SatuCard-team-starter/README.md). Сервер использует секретный ключ Supabase только в переменных окружения Vercel; не добавляйте его в GitHub.
